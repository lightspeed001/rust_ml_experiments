# phyics
## N-Body Physics Simulation
#### 1024 particles with gravitational forces on GPU

### Build and Run it :hammer_and_pick:

  > * __Run it Locally__:
    
    ```bash
          cargo run --release
     ```  

  > * __Build and Run it Docker__:
    
    ```bash
          docker build -t physics .
          docker run -it physics
     ```
