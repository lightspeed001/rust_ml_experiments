# parallel_reduction
## Custom CUDA Kernel with rustacuda (Parallel Reduction)
#### Sum an array of 1M floats using parallel reduction (O(log n) steps).

### Build and Run it :hammer_and_pick:

  > * __Run it Locally__:
    
    ```bash
          cargo run --release
     ```  

  > * __Build and Run it Docker__:
    
    ```bash
          docker build -t mandelbrot .
          docker run -it mandelbrot
     ```
