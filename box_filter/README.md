# box_filter
## GPU-Accelerated Image Blur (Box Filter)  
#### Apply a 3x3 box blur to an image using CUDA.

### Build and Run it :hammer_and_pick:

  > * __Run it Locally__:
    
    ```bash
          cargo run --release
     ```  

  > * __Build and Run it Docker__:
    
    ```bash
          docker build -t box_filter .
          docker run -it box_filter
     ```
