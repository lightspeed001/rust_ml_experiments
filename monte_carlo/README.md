# monte_carlo
## Monte Carlo Pi Estimation
#### Estimate π by sampling random points on GPU.

### Build and Run it :hammer_and_pick:

  > * __Run it Locally__:
    
    ```bash
          cargo run --release
     ```  

  > * __Build and Run it Docker__:
    
    ```bash
          docker build -t monte_carlo .
          docker run -it monte_carlo
     ```
