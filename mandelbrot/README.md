# mandelbrot
## Mandelbrot Set Rendering
#### Render the Mandelbrot fractal on GPU (each pixel = 1 thread).

### Build and Run it :hammer_and_pick:

  > * __Run it Locally__:
    
    ```bash
          cargo run --release
     ```  

  > * __Build and Run it Docker__:
    
    ```bash
          docker build -t mandelbrot .
          docker run -it mandelbrot
     ```
